Add Fikko to your home screen

About 30 seconds. Free, and nothing to download from an app store.

Fikko then opens full screen from its own icon, like any other app, so checking in takes one tap. You stay signed in, and it updates by itself.

iPhone and iPad

  1. Open app.fikko.io in Safari and sign in.
  2. Tap the Share button: the square with an arrow pointing up. In newer versions of Safari it’s inside the ⋯ menu next to the address bar.
  3. Scroll down and tap Add to Home Screen. If you don’t see it, tap Edit Actions at the bottom and add it.
  4. Make sure Open as Web App is on, if you see it, then tap Add.

Using Chrome or another browser on iPhone? It works there too on iOS 16.4 and later: tap Share in the address bar, then Add to Home Screen. On older versions, use Safari.

Android

  1. Open app.fikko.io in Chrome and sign in.
  2. If you see Install Fikko on the Habits page or at the bottom of the screen, tap it, then Install. That’s it.
  3. Otherwise, tap the menu ⋮ at the top right, then Install app or Add to Home screen.

On Samsung Internet, tap the menu ≡, then Add page to → Home screen.

Computer

In Chrome or Edge, click the install icon at the right of the address bar (a screen with a down arrow), then Install. Fikko gets its own window and a place in your dock or Start menu.

Questions

  • Is it safe? Yes. It’s the same Fikko you use in the browser, with the same privacy protections. Nothing extra is installed.
  • Do I need to update it? No. It always opens the latest version. If something looks out of date, close it fully and open it again.
  • Will reminders come as notifications? Not yet: reminders come by email, and you can set them in Profile → Reminders. Phone notifications will come with the Fikko app for iPhone.
  • How do I remove it? Press and hold the icon, then choose Remove or Uninstall. Your account and data stay.
