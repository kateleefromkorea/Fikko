# Photos for Fikko's recipes

Put a photo here named after the recipe's `key` in `src/lib/recipeCatalog.ts`,
for example `fikko-lemon-herb-chicken.jpg`. It's picked up automatically on
the next build; recipes without a photo keep their illustrated tile.

- Formats: `.jpg`, `.jpeg`, `.png` or `.webp`.
- Size: about 1200px wide is plenty. Keep each file under ~300 KB so the page stays fast.
- Only use photos you took or have the right to use (for example Unsplash or
  Pexels, checking each photo's licence).
